# Хөгжүүлэлтийн дараалал

Одоогийн хэрэгжүүлэлт: бүртгэл, нэг удаагийн мэйл баталгаажуулалт, мэйл + нууц үгээр нэвтрэх, төхөөрөмж дээр сануулах, өөрийн мэдээлэл авах, гарах. Доорх мэдээ, бодлого, quiz, rank модулиуд нь дараагийн үе шатны төлөвлөгөө.

## 1. Мэдээ, ангилал

Хэрэглэгчийн өгсөн use case-д суурилсан эрхийн матриц:

| Үйлдэл | Оюутан | Багш | Админ |
| --- | --- | --- | --- |
| Мэдээ харах, хайх, ангиллаар шүүх | Тийм | Тийм | Тийм |
| Мэдээ оруулах | Тийм | Тийм | Тийм |
| Мэдээ засах, устгах | Зөвхөн өөрийн | Бүх мэдээ | Бүх мэдээ |
| Ангилал удирдах | Үгүй | Үгүй | Тийм |
| Хэрэглэгч удирдах, эрх тохируулах | Үгүй | Үгүй | Тийм |

Моделийн суурь: `Category`, `News`. Мэдээнд гарчиг, агуулга, зохиогч, ангилал, үүсгэсэн/зассан огноо байна. API нь pagination, текст хайлт, ангиллын filter-тэй байна. Засах/устгах эрхийг backend дээр хүсэлт бүрээр шалгана.

## 2. Бодлого ба quiz

| Боломж | Оюутан | Багш | Админ |
| --- | --- | --- | --- |
| Бодлого харах, хариу илгээх | Тийм | Тийм | Тийм |
| Quiz өгөх, өөрийн үр дүн харах | Тийм | Тийм | Тийм |
| Бодлого/quiz үүсгэх, засах | Үгүй | Тийм | Тийм |
| Бусдын оролдлого, оноо хянах | Үгүй | Өөрийн сургалтын хүрээнд | Бүх |
| Rank/leaderboard харах | Тийм | Тийм | Тийм |

Энэ хүснэгт бол санал болгосон дараагийн шатны эрхийн загвар. “Багшийн сургалтын хүрээ”-г хэрэгжүүлэх үед хичээл/анги эсвэл эзэмшилтэй холбож тодорхойлно.

- `Problem`, `Submission`: бодлогын тайлбар, төрөл, түвшин, серверийн шалгалт, илгээсэн хариу, үр дүн.
- `Quiz`, `Question`, `Choice`, `QuizAttempt`, `Answer`: асуулт, сонголт, хугацаа, онооны дүрэм, оролдлогын бүртгэл.
- Бодлого/quiz-д тайлбар, сургалтын материалын холбоос нэмэх. Файл хавсаргах хэрэгцээг хадгалах сан, хэмжээ, төрлийн дүрэмтэй нь хамт шийднэ.
- Зөв хариу болон онооны түлхүүрийг quiz өгөх API-ийн хариунд ил гаргахгүй. Үр дүн үзүүлэх бодлогыг quiz бүрд тохируулна.

## 3. Rank, XP, түвшин

`ScoreEvent` бүртгэлд баталгаажсан зөв хариу/quiz-ийн үр дүнгээр XP нэмнэ. Оноог сервер тооцно; frontend-ээс ирсэн XP, rank, зөв/буруу тэмдэглэгээг итгэмжлэхгүй. Нэг амжилтаар XP давхар нэмэгдэхгүй байх unique нөхцөл болон transaction ашиглана.

Leaderboard нь нийт/сарын/хичээлийн хүрээтэй байж болно. XP-ээс түвшин тооцох дүрэм, давтан quiz өгөхөд тооцох оноо, ижил онооны эрэмбийн дүрмийг энэ үе шатанд тогтооно. Frontend нь онооны тайлан, түвшин, эрэмбийг API-аас авна.

## Дараагийн auth сайжруулалт

Нууц үг мартсан үед мэйлээр сэргээх, нууц үг солих, бүх төхөөрөмжөөс гарах, audit log. Багш/админ эрхийг нээлттэй бүртгэлээс олгохгүй.

# МТС — Оюутны мэдээллийн систем

Мандах Их Сургуулийн Мэдээлэл, технологийн сургуулийн оюутнуудад зориулсан Flutter аппын эхний 3 хуудасны прототип. Өгсөн Figma зургуудын өнгө, карт, цэс, агуулгыг баримталсан. Login хуудас ороогүй.

## Хуудас, үйлдлүүд

- **Нүүр:** шинэ зарлалын дэлгэрэнгүй, өнөөдрийн хичээл, гараг сонгох долоо хоногийн хуваарь.
- **Community:** Бүгд / Зар / Асуулт / Багш шүүлтүүр; зар, асуулт нийтлэх; үнэ оруулах; like хийх; сэтгэгдэл бичих. Багш, сургалтын албаны зарлал demo өгөгдөлтэй.
- **Сургалт:** Software Engineering / Information System хөтөлбөр сонгох; хөтөлбөр бүрийн 3 асуулттай quiz; хялбар / дунд / хүнд богино бодлого; зөв хариултын тайлбар; XP, жишээ rank.
- Доод цэсний **Профайл** товч demo оюутны мэдээллийг bottom sheet-ээр харуулна. Дөрөв дэх бүтэн хуудас биш.
- Баруун дээд товчоор гэгээтэй / харанхуй горим солино. Хуудас бүр гүйлгэгддэг; өргөн дэлгэц дээр агуулгын өргөн хязгаарлагдана.

## Ажиллуулах

Flutter stable SDK (Dart 3.8+) болон Android Studio эсвэл Chrome шаардлагатай.

```bash
flutter pub get
flutter run -d chrome
```

Android emulator эсвэл USB debugging асаасан утсаар:

```bash
flutter devices
flutter run
```

Энэ орчинд SDK-г `/tmp/flutter` дотор татаж шалгасан бол `flutter` командын оронд `/tmp/flutter/bin/flutter` хэрэглэж болно. `/tmp` цэвэрлэгдэж болох тул байнгын хэрэглээнд Flutter SDK-г өөрийн хөгжүүлэлтийн хавтаст суулган PATH-д нэмнэ.

## Шалгах, build хийх

```bash
dart format lib test
flutter analyze
flutter test
flutter build web
flutter build apk --release
```

Android build-д Android SDK, JDK шаардлагатай. iOS build-ийг macOS + Xcode орчинд хийнэ.

## Кодын бүтэц

```text
lib/
  main.dart                   # Апп, үндсэн цэс, профайл
  theme.dart                  # Өнгө, light/dark theme
  models/post.dart            # Нийтлэл, demo өгөгдөл
  models/learning.dart        # Quiz, бодлого, XP
  screens/home_screen.dart
  screens/community_screen.dart
  screens/learning_screen.dart
  widgets/ui.dart             # Дахин ашиглах карт, товч, таб
test/app_test.dart            # Үндсэн үйлдлийн widget/unit шалгалт
```

## Прототипийн хязгаар

Өгөгдөл одоогоор аппын санах ойд хадгалагдана: хуудас солиход үлдэнэ, аппыг дахин эхлүүлэхэд reset хийнэ. Backend, нэвтрэлт, бодит чат, багшийн эрх, серверийн rank холбогдоогүй. Сэтгэгдэл нь нийтлэл доторх харилцааны demo юм.

Quiz-ийн зөв хариулт бүр 20 XP; бодлого 20 / 40 / 60 XP өгнө. Үйл ажиллагаа тус бүрийн XP-г нэг удаа авна. Rank-ийн эхний гурван оюутан тогтмол жишээ өгөгдөл бөгөөд бусад оюутны бүтэн жагсаалт байхгүй тул тэднийг даваагүй үед өөрийн байр #12 хэвээр байна.

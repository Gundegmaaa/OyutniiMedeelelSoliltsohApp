# МТС — Оюутны мэдээллийн систем

Мандах Их Сургуулийн Мэдээлэл, технологийн сургуулийн оюутнуудад зориулсан Flutter аппын эхний 3 хуудасны прототип. Нил ягаан градиент, өнгөлөг карт, тоглоомын хэв маягтай сургалтын загвартай. Login хуудас ороогүй.

## Хуудас, үйлдлүүд

- **Нүүр:** шинэ зарлалын дэлгэрэнгүй, сар солих, өдөр сонгох календарь, сонгосон өдрийн хичээлийн хуваарь, өнөөдөр рүү буцах үйлдэл. Шалгалт, бие даалт, семинар болон бусад чухал өдрийг гарчиг, тайлбар, хүсвэл цагтай нь тэмдэглэх, засах, устгах боломжтой. Календарь дээр төрлөөр ялгасан өнгөт цэг харагдана.
- **Community:** Бүгд / Зар / Асуулт / Багш шүүлтүүр; зар, асуулт нийтлэх; үнэ болон төхөөрөмжөөс зураг оруулах; зургийг урьдчилан харах, солих, хасах, томруулж үзэх; like хийх; сэтгэгдэл бичих. Багш, сургалтын албаны зарлал demo өгөгдөлтэй.
- **Сургалт:** Software Engineering / Information System хөтөлбөр сонгох; хөтөлбөр бүрийн 3 асуулттай quiz; хялбар / дунд / хүнд богино бодлого; зөв хариултын тайлбар; XP, жишээ rank.
- Доод цэсний **Профайл** товч demo оюутны мэдээллийг bottom sheet-ээр харуулна. Дөрөв дэх бүтэн хуудас биш.
- Баруун дээд товчоор гэгээтэй / харанхуй горим солино. Хуудас бүр гүйлгэгддэг; өргөн дэлгэц дээр агуулгын өргөн хязгаарлагдана.

## Ажиллуулах

Flutter stable SDK (Dart 3.8+) болон Android Studio эсвэл Chrome шаардлагатай.

```bash
flutter pub get
flutter run -d chrome
```

Android emulator эсвэл USB debugging асаасан утсаар:

```bash
flutter devices
flutter run
```

Энэ орчинд SDK-г `/tmp/flutter` дотор татаж шалгасан бол `flutter` командын оронд `/tmp/flutter/bin/flutter` хэрэглэж болно. `/tmp` цэвэрлэгдэж болох тул байнгын хэрэглээнд Flutter SDK-г өөрийн хөгжүүлэлтийн хавтаст суулган PATH-д нэмнэ.

## Шалгах, build хийх

```bash
dart format lib test
flutter analyze
flutter test
flutter build web
flutter build apk --release
```

Android build-д Android SDK, JDK шаардлагатай. iOS build-ийг macOS + Xcode орчинд хийнэ.

## Прототипийн хязгаар

Нийтлэл, зураг, сэтгэгдэл, сургалтын XP одоогоор аппын санах ойд хадгалагдана: хуудас солиход үлдэнэ, аппыг дахин эхлүүлэхэд reset хийнэ. Backend, нэвтрэлт, бодит чат, багшийн эрх, серверийн rank холбогдоогүй. Сэтгэгдэл нь нийтлэл доторх харилцааны demo юм.

Календарийн чухал өдрийн тэмдэглэлүүд төхөөрөмж дээр хадгалагдана. **Нүүр → календарийн өдөр → Чухал өдрүүд → Нэмэх** сонгоод төрөл, гарчиг, огноо, хүсвэл цаг/тайлбар оруулж хадгална. Нэг өдөр хэд хэдэн тэмдэглэл оруулж болно. Аппыг дахин нээхэд тэмдэглэлүүд үлдэнэ; браузерын өгөгдөл эсвэл аппын хадгалалтыг цэвэрлэхэд арилна. Төхөөрөмжүүд хооронд синк хийхгүй, notification илгээхгүй.

Web хөгжүүлэлтийн үед Flutter-ийн Chrome цонх түр профайл ашигладаг. Тэмдэглэлээ дараагийн ажиллуулалтдаа хадгалж үлдээхийн тулд `flutter run -d web-server --web-port=5000` ажиллуулаад өөрийн энгийн браузераар `http://localhost:5000` нээнэ. Цаашид ижил браузерын профайл, хаяг, портоо ашиглана.

Зурагтай нийтлэл туршихдаа **Community → + → Зураг нэмэх** сонгоно. Зургаа сонгож, гарчиг болон тайлбараа бөглөөд **Нийтлэх** дарна. Зураг нийтлэлийн хамт санах ойд хадгалагдана; серверт байршуулахгүй.

Quiz-ийн зөв хариулт бүр 20 XP; бодлого 20 / 40 / 60 XP өгнө. Үйл ажиллагаа тус бүрийн XP-г нэг удаа авна. Rank-ийн эхний гурван оюутан тогтмол жишээ өгөгдөл бөгөөд бусад оюутны бүтэн жагсаалт байхгүй тул тэднийг даваагүй үед өөрийн байр #12 хэвээр байна. Энэ нь бодит сургуулийн чансаа биш.
